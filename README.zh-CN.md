# SurgView-VLA

**面向腹腔镜自主持镜的任务驱动视野到动作学习**

[English](README.md)

本仓库是 SurgView-VLA 的首批部分代码，论文已投稿 IPCAI 2027。

> **发布状态：核心方法预览。完整代码、训练配置和复现说明将尽快补齐。**

## 这一版提供什么

公开研究代码中已有的三个主要环节：

1. **看什么：** `What2ViewV0` 用任务语义调制空间视觉特征，预测注意力及目标可见性，再加权汇聚得到操作区域特征 `z_op`。
2. **视野应如何变化：** `Where2ViewV1` 分别预测当前与期望视野描述，在同一描述空间内计算 `e_view = g_des - g_cur`。同时提供带尺度残差门控的 `Where2ViewV11`。
3. **如何移动相机：** `ActionHead` 根据条件向量预测动作流，使用零初始化与 32 步 Euler 积分生成 8×4 动作块，四维依次对应 yaw、pitch、roll、insertion。

这些模块从已有研究实现中抽取，保留原有版本名称，仅调整打包方式和解释性注释，没有修改模型计算。它们展示主要算法，但尚未覆盖论文的全部系统。

## 关于视野做差

当前视野与期望视野都由当前输入特征预测；未来专家视野用于训练监督，不是推理输入。两组四维描述经过相同的反归一化后相减，得到一个四维视野误差。

论文中的描述为 `[中心横坐标, 中心纵坐标, log(sqrt(面积)), 相对深度]`。这个四维视野误差与策略输出的八步动作序列是不同概念。该预览未包含监督标签生成或数据集归一化统计。

## 运行示例

安装步骤见英文 README。安装后运行：

```bash
python -m examples.synthetic_forward
python -m unittest discover -s tests -v
```

示例使用随机输入和随机初始化参数，只用于检查模块接口及张量形状，不用于复现论文结果。示例策略条件由 `z_op`、`e_view` 和四维相机状态拼接而成；完整时序上下文、训练归一化和视觉骨干尚未接入。
